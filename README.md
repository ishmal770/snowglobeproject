**DeFrost!**

A two player interactive game including components of story telling, and real time visual analysis. This game is aimed towards teenagers.

The story of the game follows the two players representing Elsa and Anna from Frozen, determined to save Olaf who has frozen. To unfreeze him they work together, learning small 10 second segments of tik tok dances and performing it to the best of their ability, and earning stars likewise. If the accuracy of the moves exceeds 80% they can do another dance and earn between 4 to 5 stars otherwise they earn rating between 1 to 3. Earning stars help unfreeze Olaf!

To play the game the user should press the link and follow the instruction on the screen, the game uses a webcam and it should be unblocked.

The art is made using pixel art and uses a muted colour scheme from the Pixilart website. The real time visual analysis is done using MediaPipe, a library in python. The website is made using html as a base, css as a stylesheet and java script for functionality.

We used tutorials of how to publish and render on Vercel and how to animate in css.
